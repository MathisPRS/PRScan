# PRScan

A personal PWA (Progressive Web App) for scanning documents, converting images to PDF, and managing files — all stored locally in the browser via IndexedDB. Installable on iOS via Safari "Add to Home Screen".

---

## Features

- **Scan Document** — camera-based document scanner with auto edge detection
- **Picture to PDF** — convert photos from your library into a PDF
- **File Manager** — browse, rename, delete, preview and upload files to cloud
- **Cloud upload** — Google Drive (OAuth PKCE), OneDrive (MSAL.js), iCloud (stub)
- **PWA** — installable on iOS/Android, works offline after first load
- **Bilingual** — English / French

---

## Tech stack

| Layer | Library |
|---|---|
| UI | React 19 + TypeScript 6 |
| Routing | React Router v7 |
| Bundler | Vite 7 |
| PWA | vite-plugin-pwa 1.2 |
| PDF | jsPDF 4 |
| Icons | lucide-react 1 |
| Storage | IndexedDB via `idb` |
| Cloud | @azure/msal-browser (OneDrive), fetch PKCE (Google Drive) |

## Setup

### 1. Install Node.js via nvm (recommended)

```bash
# Install nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash

# Reload shell
source ~/.bashrc   # or ~/.zshrc on zsh

# Install and use Node 24
nvm install 24
nvm use 24
nvm alias default 24
```

Verify:
```bash
node -v   # v24.x.x
npm -v    # v11.x.x
```

### 2. Clone the repo

```bash
git clone <your-repo-url>
cd PRScan
```

### 3. Install dependencies

```bash
npm install
```

## Development

Start the local dev server with hot-reload:

```bash
source ~/.nvm/nvm.sh && nvm use 24
npm run dev
```

Open **http://localhost:5173** in your browser.

If port 5173 is already in use:
```bash
kill $(lsof -ti :5173)
npm run dev
```

## Build for production

Compiles TypeScript and produces optimized files in `dist/`:

```bash
source ~/.nvm/nvm.sh && nvm use 24
npm run build
```

Preview the production build locally:
```bash
npm run preview
```

Open **http://localhost:4173**.

## Deploy

### Vercel (recommended)

**First time:**
```bash
npm i -g vercel
vercel login
vercel --prod
```

Vercel auto-detects `dist/` as the output folder. No extra config needed.

**Subsequent deploys:**
```bash
source ~/.nvm/nvm.sh && nvm use 24
npm run build
vercel --prod
```

### Any static host (Netlify, GitHub Pages, etc.)

Upload / deploy the contents of the `dist/` folder. Make sure the host serves `index.html` for all routes (SPA fallback).

## Cloud credentials

Credentials are **not committed**. To enable cloud upload, set the following constants in `src/services/cloudService.ts`:

```ts
const GOOGLE_CLIENT_ID = 'YOUR_GOOGLE_CLIENT_ID';
const MSFT_CLIENT_ID   = 'YOUR_AZURE_APP_CLIENT_ID';
```

- **Google Drive**: create an OAuth 2.0 client ID at [console.cloud.google.com](https://console.cloud.google.com) with `http://localhost:5173` (dev) and your production URL as authorized redirect URIs.
- **OneDrive**: register an app at [portal.azure.com](https://portal.azure.com), add the same redirect URIs, and enable `Files.ReadWrite` scope.
- **iCloud**: requires an Apple Developer account ($99/year) — currently a stub only.

## Notes

- All files are stored **locally in IndexedDB** — clearing browser data deletes everything.
- The PWA service worker is generated by Workbox via vite-plugin-pwa.
- The app is designed for **personal use only** — no authentication, no backend.
